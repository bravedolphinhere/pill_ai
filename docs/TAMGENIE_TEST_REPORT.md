## 테스트 범위와 제한

Streamlit AppTest에서 업로드 반환값만 주입한 뒤 실제 `app.py`를 실행했다.
실제 YOLO11n 가중치·GPU·Crop·질문 화면을 사용했고,
브라우저 파일 선택 창이나 브라우저 렌더링을 자동화한 것은 아니다.
직접 브라우저 화면 검수는 도구가 현재 URL을 검증할 수 없어 중단됐다.
모바일·다중 사용자 부하·외부 공개 배포·학습 범위 밖 약품의 판별은 미검증이다.

EfficientNet-B0는 미구현이다. 불일치 처리는 가상2차 분류기를 주입한 단위 테스트로만 확인했다.
가상의 예측을 사용자 화면에서 실제 EfficientNet-B0 결과처럼 표시하지 않았다.
출처 확인 속성이2종에 한정돼 대부분의 후보를 질문만으로 특정할 수 없다.
점수0.25·추가 확인0.60·품질 규칙의 임계값은 신뢰성을 보장하는 기준이 아니다.
